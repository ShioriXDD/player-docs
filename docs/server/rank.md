# 会员等级

*本文最后更新于 2025.3.19*

购买会员以获得一系列好玩又酷炫的小玩意儿，还能让腐竹有更多的钱来养活服务器

?> 所有会员等级已暂停新购

---------

## 如何获(bai)得(piao)

- <s>通过官网商店购买</s>
- <s>跟腐竹混眼熟以白嫖会员</s>
- 提高服务器等级可免费获得永久会员（具体参见[等级系统](https://docs.usolia.net/#/docs/server/level)）
- 部分礼包，包括免费礼包也会包含会员等级
- 参加服务器不定期举办的大型活动
